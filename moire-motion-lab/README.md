# 重疊之間 / Moiré Motion Lab

以 Two.js SVG renderer 製作的獨立互動作品網頁。兩層規律直線形成莫列紋；上層運用 Two.js `bind('update')` 與 `play()` 持續移動、輕微旋轉。觀看者可用手指或滑鼠暫時接手，也可調整間距、角度、粗細、水平位移與速度，或暫停觀看。圖像可匯出成 SVG。系統設定為減少動態時，預設暫停。

## 創作紀錄 · v1 / 2026-09-25

- 問題：兩個簡單規律重疊，為什麼會看見更大的波紋？
- 操作：先拖曳，再固定其他條件，一次調整一個參數。
- 動態：規律自行緩緩改變；手指按住時時間暫停，放開後繼續。
- 觀察：辨別圖層實際移動的位置與眼睛感受到的運動。
- 技術：靜態 HTML、CSS、JavaScript 與固定版本的 Two.js；無需建置流程。首次載入需要網路取得函式庫。
- 範圍：GitHub 作品實驗，尚未列入作品集首頁或 iPadArt.net 正式文章。
