# CyberFair 2019 Emergency Preservation

Source: https://cyber2019.rfjh.ntpc.edu.tw/index.htm

Emergency preservation snapshot of the public 2019 International CyberFair site before the school DNS record is retired.

- `raw/` is the primary preservation crawl, keeping downloaded response bytes intact.
- `portable/` is a byte-identical working copy reserved for offline/static-host validation.
- `wget-fallback/` is an independent secondary recovery pass seeded from nine known core pages.
- `metadata/` contains DNS/HTTP capture, crawl manifest/errors, inventories, SHA-256 checksums, sizes, and recovery logs.

Preservation first: no editorial redesign or modernization has been applied.
