# 形在呼吸 / Geometry in Motion

Two.js 互動幾何作品：圓、方與三角形依各自的節奏運動，指標或手指形成吸引或推開的力場。觀眾可改變密度、速度與回應距離，暫停並將構圖保存為 SVG。

## 創作紀錄 · 2026-09-25

- 問題：規律運動的幾何形狀能否在觀眾靠近後形成新的關係？
- 作法：以 Two.js scene graph 建立形狀與連線，以 `bind('update')` 驅動時間與回復運動；每個形狀都有自己的速度、慣性與位置。
- 操作：滑鼠靠近，或在觸控裝置按住並移動；切換吸引／推開，觀察同一組形狀如何重組。
- 觀看：先看，再操作，再暫停。保存意外產生的構圖並為它命名。
- 與《重疊之間》的關係：後者研究莫列疊影，本作品研究形狀間的運動與互動。
- 技術：靜態 HTML、CSS、JavaScript；Two.js 版本固定為 0.8.24，由 CDN 載入。減少動態偏好下預設暫停。
